# フュージョン将棋

依存なしで動作するブラウザ版のフュージョン将棋です。

## 起動

```bash
npm test
npm start
```

ブラウザで `http://localhost:4173/` を開いてください。

ゲームエンジンは `src/game.js` にあり、通常将棋の合法手判定（王手放置、成り、二歩、行き所のない駒打ち、打ち歩詰め）に加えて、融合駒を扱います。

盤の左右にある「指し手」設定で、先手・後手をそれぞれ「人間」または「コンピュータ」に切り替えられます。コンピュータは合法手の中から、融合・駒取り・成り・王手を優先して自動で指します。

CPUの探索処理は `src/ai/engine.js` に分離されています。`ComputerEngine` は画面に依存せず、局面を渡して指し手を選べます。探索にはmake/unmake、アルファベータ枝刈り、置換表、killer/history手順付け、王手・駒取り・成り・融合を読む静的探索を使用します。評価には駒の位置・進行度、王の安全、攻撃と守備、持ち駒の打ち込み価値、局面の序盤／終盤差、融合ペアの相性を反映します。直近の探索結果は `getLastSearchStats()` で、完了深さ・探索ノード数・置換表ヒット数などを確認できます。

CPUの強さは画面上部の「CPU強さ」から「やさしい」「標準」「強い」を選べます。設定変更中の探索は安全にキャンセルされ、次のCPU手番から新しい設定を使います。チューニングの確認には `npm run benchmark` を使えます。引数で自己対局の最大手数を指定できます（例: `npm run benchmark -- 20`）。ベンチマークでは各レベルの初手の探索深さ・ノード数と、短い自己対局での合法手検証を出力します。
